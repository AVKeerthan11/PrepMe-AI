# Subject Images

Place subject card images in this directory with the following filenames:

- `science.png` - Yellow-themed Science card (recommended: 200x200px or larger)
- `maths.png` - Blue-themed Mathematics card
- `social.png` - Red-themed Social Studies card  
- `english.png` - Violet-themed English card

If an image is missing, the UI will gracefully fall back to showing the first letter of the subject name in a colored box.

## Image Guidelines

- Use PNG format with transparency if needed
- Recommended size: 200x200px minimum (displayed at ~96px)
- Keep file sizes reasonable (< 100KB per image)
- Ensure good contrast against the colored backgrounds:
  - Science: #FFF9E6 background, #E6B800 accent
  - Math: #F0F4F8 background, #4A6FA5 accent
  - Social: #FDF2F2 background, #E05252 accent
  - English: #F5F3FF background, #8B5CF6 accent
